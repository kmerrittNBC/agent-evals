**No upgrade is needed for either use case.** Both capabilities arrived in Playwright **v1.60.0** (released May 11, 2026); RelayView’s lockfile pins **1.62.1**, which is newer.

- **Record a HAR through tracing:** `context.tracing.startHar(path)` starts recording and `context.tracing.stopHar()` saves it; the returned disposable can also end recording. Only one HAR recording can be active per tracing instance. This is a separate HAR artifact—not the regular Playwright trace ZIP. The older `recordHar` browser-context option predates it (v1.23). [v1.60 release notes](https://playwright.dev/docs/release-notes#version-160) · [Tracing API](https://playwright.dev/docs/api/class-tracing#tracing-start-har)
- **Drop a file onto a custom element:** `locator.drop({ files: ... })` was also added in v1.60. It simulates an external file drop with a synthetic `DataTransfer` and dispatches `dragenter`, `dragover`, and `drop`; Playwright says it works cross-browser. The target must accept the drag by calling `preventDefault()` in its `dragover` handler, or Playwright throws. There’s no documented custom-element-specific restriction: a locator for the custom-element host targets the host. Locators also pierce **open** shadow roots, but closed-mode shadow roots aren’t supported. [v1.60 release notes](https://playwright.dev/docs/release-notes#version-160) · [Locator `drop()` API](https://playwright.dev/docs/api/class-locator#locator-drop) · [Shadow DOM locator support](https://playwright.dev/docs/locators#locate-in-shadow-dom)

**RelayView configuration and recommendation:** `relayview/browser/playwright.config.ts` runs Chromium only and doesn’t configure tracing; the showcase and workflow configs are also Chromium-only. `relayview/package.json` declares `^1.62.1`, while `relayview/package-lock.json` pins 1.62.1. For a test that needs a HAR, start and stop `context.tracing.startHar(...)` around the relevant actions and save it under that test’s output path. For ordinary failure-debugging traces, configure Playwright Test’s `use.trace` separately; that captures test assertions, unlike the low-level `context.tracing` API.
