**Yes—RelayView’s pinned Playwright 1.62.1 supports both. No upgrade is needed.** Both capabilities first appeared in **Playwright 1.60**, released **May 11, 2026** ([release notes](https://playwright.dev/docs/release-notes), [official release page](https://github.com/microsoft/playwright/releases/tag/v1.60.0)).

- **HAR recording through tracing:** Playwright 1.60 added `context.tracing.startHar(...)` and `context.tracing.stopHar()`. This records a HAR for a browser context; it is distinct from `context.tracing.start()` / `stop()`, which produce a Playwright trace, not a HAR. Only one HAR recording can be active per tracing instance. ([Tracing API](https://playwright.dev/docs/api/class-tracing))
- **Dropping a file onto a custom element:** Playwright 1.60 added `locator.drop(...)`. It accepts file paths or in-memory file buffers and can target a locator for a custom element. It dispatches `dragenter`, `dragover`, and `drop` with a synthetic `DataTransfer`; if the target’s `dragover` handler doesn’t call `preventDefault()`, Playwright treats the drop as rejected and throws. The API is documented as cross-browser, but it simulates page events—it is not a physical OS-level drag. ([Locator API](https://playwright.dev/docs/api/class-locator))

**RelayView configuration:** `package.json` declares `@playwright/test: ^1.62.1`, and `package-lock.json` pins `@playwright/test`, `playwright`, and `playwright-core` to **1.62.1**. The main config, [`browser/playwright.config.ts`](relayview/browser/playwright.config.ts), and the showcase and workflow configs all set `browserName: "chromium"`. So the APIs are available, but RelayView’s current runs exercise them only in Chromium.

**Recommendation:** For a test-scoped HAR, start and stop `context.tracing`’s HAR recording around the scenario, ensuring it is stopped during cleanup. For a file drop, use `page.locator('your-upload-element').drop({ files: { name, mimeType, buffer } })` and assert the resulting application behavior. Add Firefox/WebKit projects only if cross-browser coverage is desired.
