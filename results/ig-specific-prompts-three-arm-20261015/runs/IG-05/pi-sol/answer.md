**As of October 14, 2026, Node 24.x is the best common target** for this workspace, provided it is **24.15.0 or newer**. The repository’s existing `.nvmrc` pins **24.16.0**, which meets the documented ranges; CI workflows that use `.nvmrc` will use that same version.

| Component | Documented compatibility relevant to this workspace |
|---|---|
| Angular 22 | The [Angular compatibility table](https://angular.dev/reference/versions) lists **22.0.x**—but does **not separately list 22.1.x**—with Node `^22.22.3 \|\| ^24.15.0 \|\| ^26.0.0` and TypeScript `>=6.0.0 <6.1.0`. TypeScript **6.0.3** fits that range. Applying the Node/TypeScript row to **22.1.7** is an inference, not an explicitly published 22.1.x row. |
| Nx 23.2.1 | Nx’s [Angular–Nx matrix](https://nx.dev/docs/kb/angular-nx-version-matrix) explicitly lists Angular `~22.1.0` with **Nx `>=23.2.0`**, so 23.2.1 qualifies. Nx’s [Node table](https://nx.dev/docs/technologies/node/introduction) lists **22.x from 22.12.0, 24.x, and 26.x** for Nx 23; its [TypeScript table](https://nx.dev/docs/technologies/typescript/introduction) lists **`>=5.8.0 <7.1.0`**. Angular sets the stricter Node and TypeScript limits. |
| Playwright 1.60 | The [Playwright installation docs](https://playwright.dev/docs/intro) list the latest **Node 22.x, 24.x, or 26.x**. They are rolling installation guidance, not an explicit Node matrix for the pinned 1.60 release. Its [TypeScript docs](https://playwright.dev/docs/test-typescript) do not establish a TypeScript 6 support range; Playwright transpiles tests but does not type-check them. |

**Gaps and conflicts:** Angular’s missing **22.1.x** row prevents claiming an explicit, fully documented Angular 22.1.7 compatibility tuple, even though Nx explicitly covers that minor version. The repository’s `AGENTS.md` still says `.nvmrc` selects **Node 20.20.0**; the actual `.nvmrc` says **24.16.0**. Node 20 is outside both Angular 22’s and Nx 23’s documented support. Playwright’s documentation also should not be read as a guarantee for every Node/TypeScript combination of release 1.60.

**Recommendation:** Keep local development and CI on the **same pinned Node 24.x version**, currently **24.16.0** in `financial-hq-ui/.nvmrc`; move both together to a newer patched 24.x release when validated. Node 24 is within every stated Node range and was Active LTS on the requested date. Node 22 requires at least **22.22.3** under Angular’s table; Node 26 is listed but was not yet LTS on October 14. Update the stale Node 20 instruction in `financial-hq-ui/AGENTS.md`, and run the workspace build, tests, and a separate TypeScript type-check to verify the documentation gap in practice.
